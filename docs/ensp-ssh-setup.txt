eNSP 设备 SSH（stelnet）开启脚本
用途：让网管系统能通过 SSH 采集 display 命令，验收检查项才有真实数据
现状：12 台设备 22 端口 TCP 可连，但回显无 SSH banner —— 说明 VRP 的
      stelnet 服务未启用（华为设备默认关闭），需逐台在 Console 口执行
================================================================

【每台设备都要做】进 Console 后粘贴以下命令（以 CORE-1 为例）

system-view
sysname CORE-1                                  // 各设备改成自己的名字
stelnet server enable
aaa
 local-user admin password cipher Admin@123
 local-user admin privilege level 15
 local-user admin service-type ssh
 quit
ssh user admin authentication-type password
ssh user admin service-type stelnet
user-interface vty 0 4
 authentication-mode aaa
 protocol inbound ssh
 quit
return
save
 y

说明：
- 账号统一 admin / Admin@123，方便后续在网管里批量录入凭据
- 若 `ssh user ...` 两条报错（部分 V200R005 之前版本不支持），可忽略，
  只保留 aaa 里的 local-user 配置即可
- 若 `stelnet server enable` 报 "RSA key pair not found"，先执行：
      rsa local-key-pair create      // 提示密钥长度时输入 2048
  再重新执行 stelnet server enable

================================================================
【验证方法】在 Windows 命令行执行（三台核心/出口各测一次）
----------------------------------------------------------------
ssh admin@10.20.10.11
出现 "Info: The max number of VTY users is 5..." 或直接进 <CORE-1> 即成功
