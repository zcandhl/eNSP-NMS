# eNSP NMS 与真实网管差距（摘要）

供能力边界与预期管理。详细能力见 [软件说明.md](软件说明.md)。

## 定位差异

| | 本产品 | 华为 eSight / NCE 等 |
|--|--------|----------------------|
| 场景 | eNSP 实验室教学 | 生产网络运维 |
| 规模 | 课堂级设备数量 | 园区 / 数据中心级 |
| 闭环 | 半闭环（关键写操作需确认） | 完整运维流程与工单生态 |
| 协议深度 | SNMP/SSH 通用纳管为主 | 厂商私有协议与专业组件齐全 |

## 已知环境限制（验收时请知悉）

1. **LLDP / 私有 MIB**：eNSP 镜像常不完整，拓扑可能依赖 ARP 等回退，链路可能不全  
2. **虚拟 PC**：一般无 SNMP，默认仅 Ping，无性能曲线  
3. **防火墙 / AC / AP**：上线、告警、上图；不做策略可视化或 WLAN 专业管理  
4. **Trap**：需设备正确指向管理机 UDP 162，并放行防火墙  
5. **LLM 助手**：可选组件，默认关闭；不作为课堂必验收项  

## 不承诺对等的能力

- 全网容量规划、复杂变更编排、多域联邦  
- 与生产 AAA / ITSM 开箱即用集成  
- 与真实硬件全型号 OID 模板完备覆盖  

若合同需要超出教学标准版的能力，应单独立项评估与报价。
